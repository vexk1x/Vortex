# About Vortex

Vortex is a free and open-source project for the Roblox game Sol's RNG. It has features like Customizable Biome / Aura Detection, Support for Multiple Accounts, Good Webhooks messages, AntiAFK to prevent you being sent to a Ghost Private Server, "Allow multiple instances" (Requires Handle64.exe, and basically closes the singleton event handle that prevents you from launching multiple clients at the same time), a decent gui (Thanks to Fiko), and much more.

# How to Download

Either download the latest version from [here](https://github.com/vexk1x/Vortex/releases)
or 

clone/download the source code and run
```C#
dotnet publish "Sol's RNG Biome Detector\Sol's RNG Biome Detector.csproj" -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

> This requires the [.Net Runtime](https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/10.0.12/windowsdesktop-runtime-10.0.12-win-x64.exe) to be installed

# Is it safe to use?

Yes, Vortex is safe to use. It's not a virus. If you don't trust the releases, then read 'How to Download' on how to build it yourself.
